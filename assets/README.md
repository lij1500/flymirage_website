# Website assets

Place optimized website media in this directory.

Suggested filenames:

- `teaser.webp` — project cover or teaser image
- `method.webp` — method or pipeline diagram
- `results.webp` — headline results figure
- `logo.webp` — institution or project logo

Prefer WebP for images. Keep large videos, datasets, and model weights on dedicated hosting and link or embed them from the website.
